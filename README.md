# 📉 Customer Churn Prediction

## 📌 Overview

Built a machine learning classification system to predict whether telecom customers are likely to leave the company (churn) using customer behavior and service-related features.

---

## 📊 Dataset

* Dataset: Telco Customer Churn Dataset
* Source: IBM Sample Dataset
* Contains customer information such as:

  * Gender
  * Contract type
  * Internet service
  * Payment method
  * Monthly charges
  * Tenure
  * Total charges
* Target Variable:

  * `Churn`

    * `1` → Customer leaves
    * `0` → Customer stays
